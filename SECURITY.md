# Security Policy

## Supported versions

Cubby is a hobby project under active development. Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, report privately to the maintainer with:

- Description of the issue
- Reproduction steps / proof of concept
- Potential impact

If your repository has GitHub Security Advisories enabled, prefer using private vulnerability reporting there.

## Response goals

- Initial acknowledgment: within 7 days
- Triage and severity assessment: as soon as possible
- Fix timeline: depends on impact and complexity
