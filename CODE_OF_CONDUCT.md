# Code of Conduct

## Our pledge

We are committed to making participation in this project a respectful and harassment-free experience for everyone.

## Our standards

Examples of behavior that contributes to a positive environment:

- Being respectful and constructive
- Accepting and giving feedback gracefully
- Focusing on what is best for the community

Examples of unacceptable behavior:

- Harassment, discrimination, or personal attacks
- Trolling, insulting, or derogatory comments
- Publishing private information without permission

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards and may remove, edit, or reject comments, commits, code, or issues that violate this Code of Conduct.

## Reporting

Please report unacceptable behavior by opening a private security/contact channel as described in [SECURITY.md](./SECURITY.md).

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests, and discussions.
